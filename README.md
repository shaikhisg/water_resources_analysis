# Geospatial Analysis: Surface Water Detection
This project demonstrates the application of Python for hydrological research, specifically focusing on automated water body extraction from multispectral satellite imagery.

## Key Features:
* **Spectral Indices:** Implementation of the Normalized Difference Water Index (NDWI).
* **Automated Processing:** Using `NumPy` for efficient matrix calculations on raster data.
* **Visualization:** Clear mapping of water boundaries vs. land surface.

## Future Work:
* Integration with Google Earth Engine (GEE).
* Time-series analysis for Aral Sea or local reservoirs in Kazakhstan.
